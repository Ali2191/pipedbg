Getting started

Quickstart

Get SecureOS running on your repo in under 3 minutes. By the end of this guide your next push will be scanned automatically and findings will land in your PRs.

Install

SecureOS is two things: a hosted control plane that watches your repos, and an open-source CLI (Sentinel) you can run anywhere. You can use either or both. Pick your install path:

Option 1 — Hosted (recommended)

No install. Sign in with GitHub, pick a repo, done.

terminal shell
$ open https://app.secureos.dev

Option 2 — CLI only

Install the Sentinel binary and run scans locally. No account needed.

macOS · brew shell
$ brew install secureos/tap/sentinel
Linux · curl shell
$ curl -fsSL https://secureos.dev/install.sh | sh
npm shell
$ npm install -g @secureos/sentinel
Heads up. The CLI is fully open source. The hosted plane adds the other 8 agents, the dashboard, and PR integration on top.

Connect GitHub

Authorize the SecureOS GitHub App. Read-only on code, write-only on PR comments. We never push commits to your repo without confirmation.

1

Authorize

Visit app.secureos.dev/auth/github and approve the install for the org or account you want to protect.

2

Pick repos

Choose the repos to enable. You can change this anytime.

app.secureos.dev/setup/repos
Select repositories · 3 of 12
acme/my-saas-app
private · last push 2 hours ago
acme/landing-v3
public · last push 6 hours ago
acme/api-gateway
private · last push 1 day ago
3

That's it

The webhook is installed. Sentinel runs on every push and PR. No YAML, no commits to your repo.

Done. Open a PR with anything and you'll see Sentinel comment within seconds.

Your first scan

You don't need to wait for a push. Trigger a one-shot scan to see what Sentinel finds in your current main branch.

scan current repo shell
$ secureos scan → sentinel · loading rulepack v2024.11 → scanning ./ → 47 files in 1.2s CRITICAL auth.js:12 Hardcoded Stripe key CRITICAL db.py:34 SQL injection via string concat HIGH config.js:8 CORS wildcard origin MEDIUM app.py:156 Debug mode enabled 4 issues · 2 critical · 1 high · 1 medium → run secureos fix <id> to apply suggested fixes

Apply fixes

Findings are numbered. Apply a fix in one line:

fix finding #2 shell
$ secureos fix 2 → generating patch for db.py:34 → applied. commit a4f2c9a
Note. Critical findings (hardcoded secrets, JWT keys) need your eyes. Sentinel will show the suggested patch and wait for confirmation. Use --auto if you've reviewed and want batch application.

GitHub Actions

Hosted SecureOS installs its webhook automatically. If you prefer to manage your own CI, drop this into .github/workflows/secureos.yml:

.github/workflows/secureos.yml yaml
name: SecureOS on: [push, pull_request] jobs: scan: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: secureos/sentinel-action@v2 with: fail-on: critical,high comment-pr: true

Editor integration

Findings inline, while you type. The VS Code extension works in Cursor too.

VS Code marketplace shell
$ code --install-extension secureos.sentinel
