How Scout thinks

STRIDE, but for products that don't exist yet.

Most threat-modeling tools want a finished system diagram. Scout works from a stack list and a one-paragraph product description — the only things you have on day one.

01 — Inputs

Stack + intent

No diagrams to draw. Just check boxes for the libraries you're using and describe what you're building.
02 — Mapping

Trust boundaries

Scout walks the data path from user to database, identifying every place authority changes hands.
03 — Output

Ranked controls

A prioritized list of mitigations Sentinel will then enforce on every commit.
